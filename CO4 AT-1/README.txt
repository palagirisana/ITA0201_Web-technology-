UNIVERSITY COURSE ENROLLMENT WEBSITE
=====================================

Technologies Used:
------------------

1. HTML5
2. CSS3
3. JavaScript
4. XML
5. XPath
6. XSLT


Files:
------

index.html
style.css
script.js
courses.xml
courses.xsl


Project Features:
-----------------

1. Home page
2. Course listing
3. Student enrollment
4. Enrollment confirmation
5. Course analysis
6. Course-wise enrollment chart
7. XML data storage
8. XPath XML processing
9. XSLT transformation
10. Responsive design


How to Run:
-----------

Method 1:

Open index.html in a browser.

If the browser blocks courses.xml, use Live Server.


Method 2:

Open the project folder in Visual Studio Code.

Right click index.html.

Select:

"Open with Live Server"


The website will open in the browser.


To view XSLT:
-------------

Open courses.xml directly in the browser.

The XML stylesheet instruction will apply courses.xsl
and display the course table.
